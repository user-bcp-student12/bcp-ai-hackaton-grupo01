# Proposal

## Why

The repository contains a workflow kit but no application. A verified local
foundation must unblock six contributors without pretending there is a deploy.

## What Changes

- Add npm workspaces, Fastify, React/Vite, shared schemas and local SQLite.
- Establish health, configuration, error handling, migration and test conventions.
- Verify Node 24 SQLite on Windows and document actual commands/versions.
- Replace public deployment with the human-approved local demonstration.
- Out of scope: feature implementation, public hosting and financial integrations.

## Capabilities

### New Capabilities

- `local-runtime`: reproducible local runtime, health and persistence lifecycle.

### Modified Capabilities

None.

Root tooling, `api`, `web`, `packages/contracts`, `AGENTS.md`, README and standards.
